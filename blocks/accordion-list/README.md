# accordion-list

Custom **accordion** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Optional heading row (one cell, a heading). Optional picture row (image-beside). Item rows [question] [answer]; the answer may hold paragraphs, lists, tables, links, or a single /fragments/ link..

## Supported variations

| Variation | Option class |
| --- | --- |
| Boxed | `boxed` |
| Image Beside | `image-beside` |
| Light | `light` |
