# anchor-nav

Custom **custom** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One cell (or one row per tab) with a list of links to in-page anchors (#why-us). Any link that is not an in-page anchor becomes the CTA button (e.g. Apply Now)..
