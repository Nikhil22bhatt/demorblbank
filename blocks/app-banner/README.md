# app-banner

Custom **carousel** block. Purpose: service-banners.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Each row is a slide: [desktop picture] [mobile picture] [link paragraph] [optional colour: aqua | sky | lavender | green | white]. Class start-N / start-mobile-N sets the initial slide..
