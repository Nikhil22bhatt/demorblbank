# article-byline

Custom **custom** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One block row; cells in any order: author photo (picture), author name (text or link), publish date (text, e.g. "Nov 20, 2025"). Optional share links (facebook/twitter/x/linkedin/whatsapp URLs); when none are authored, share links for the current page are generated for all four networks..
