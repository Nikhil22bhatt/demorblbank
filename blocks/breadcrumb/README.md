# breadcrumb

Custom **custom** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One cell with a list of links (Home, Section, ...), last item plain text for the current page. Paragraphs of links separated by '>' also work; an empty block derives the trail from the URL. An optional picture becomes a background..

| Alt | `alt` |
| Image Light | `image-light` |
