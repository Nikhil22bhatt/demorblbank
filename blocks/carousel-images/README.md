# carousel-images

Custom **carousel** block. Purpose: Image-only slide carousel with line indicators, used on CSR programme pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Each row is one slide: [picture] [optional caption text]. One row renders as a single static image; 2+ rows add prev/next buttons and line indicators.

## Supported variations

No variations.
