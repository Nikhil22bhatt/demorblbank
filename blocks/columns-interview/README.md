# columns-interview

Custom **columns** block. Purpose: Employee interview layout: intro and Q/A boxes beside a portrait image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Each row: [text cell: intro paragraph, then paragraphs starting with "Q:" and "A:"] [image cell]. Q:/A: paragraphs (plus following paragraphs) are wrapped into question/answer boxes.
