# columns-location

Custom **columns** block. Purpose: Dense multi-column rows: rate strips, method lists, ATM/branch location rows, video tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Each row: N cells of text/links/headings (icons may lead text inside a paragraph); a cell with only a picture is an image column. Single-cell rows span full width. Option alt = listing rows with dividers and top alignment.
