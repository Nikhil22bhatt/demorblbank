# columns-media

Custom **columns** block. Purpose: Text beside media (image, video embed or image slider), with boxed, grey and background-image treatments.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Each row: [text cell: heading, text, lists, CTA] [media cell: picture, a single YouTube/Vimeo/.mp4 link, or several pictures with image-slider]. Single-cell rows span full width. With background-image options, a single-cell picture-only row becomes the block background.

## Supported variations

| Variation | Option class |
