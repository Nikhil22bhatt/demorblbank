## Authoring (Document Authoring)

Repeating rows — one row per item. Each item: Each row is a slide: [desktop picture] [mobile picture] [optional copy cell: headings + CTA, or lone link = whole-slide link]. Class start-N / start-mobile-N sets the initial slide..
