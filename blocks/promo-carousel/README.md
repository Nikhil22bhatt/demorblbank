# promo-carousel

Custom **carousel** block. Purpose: promo-carousel.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: Each row is a slide: [desktop picture] [mobile picture] [heading + list/paragraph + CTA] [optional style: light | compact]. Class start-N / start-mobile-N sets the initial slide..
