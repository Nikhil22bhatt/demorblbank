# tabs-card-selector

Custom **tabs** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card: cell 1 = tab label (heading with card name + card image); cell 2 = panel content (heading, links, image, .mp4 link for video) or a single link to a fragment (e.g. /fragments/cards/platinum-maxima-plus) that is loaded when the tab is first opened..

## Supported variations

No variations.
