# video-inline

Custom **video** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row: optional title/heading text, optional poster picture, and the video link (YouTube/Vimeo/MP4). With a poster the embed loads on click; without one it loads when scrolled into view..

## Supported variations

| Variation | Option class |
| --- | --- |
| Full Width Banner | `full-width-banner` |
| Dark | `dark` |
